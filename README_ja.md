## このフォークについて — 「独立」版

[Elin Together](https://github.com/ElinTogether/ElinTogether) の改造版です。目的はひとつ：**ゲーム内で、ホストと他のプレイヤーの違いをなくすこと**。各自が好きな場所へ、自分の仲間・クエスト・名声・お金とともに行き、ワールド（ストーリー、拠点、ギルド）は共有のままです。

元の MOD は、パーティ全員をホストのマップに留め、他のプレイヤーをホストの仲間として扱います。元の作者は、別々のマップを対象外としています。このフォークは、それを試す場所です。MOD 自体の功績はすべて元の作者にあります（[クレジット](#クレジット)を参照）。

> **状態：実験的。** 以下はすべて、1 台の PC で 2 つのゲームウィンドウを開いて検証したものです（ゲーム内の自動テスト、900 項目以上、`dev/` を参照）。Steam で 2 台の PC を使ってプレイしたのは**ごくわずか**（一晩だけで、テストが見逃していたバグが見つかりました）で、このバージョンの新機能はまだ 2 台の PC で試していません。先にセーブのバックアップを取ってください：`%USERPROFILE%\AppData\LocalLow\Lafrontier\Elin`

### このフォークが追加するもの

| 機能 | 変わること |
|---|---|
| 独立した移動 | プレイヤーはホストなしで別のマップへ行けます。マップとそこでの行動は保存されます。離れている間も進行は定期的に保存され、チャットはマップをまたいで使えます。 |
| 共有マップ | ホストなしで、他のプレイヤーのマップに合流できます。マップを預かっているプレイヤーが離れると、別のプレイヤーが引き継ぎます。 |
| ホストは誰も連れ回さない | ホストがマップを移動しても、残ったプレイヤーはそのまま残ります。 |
| プレイヤーごとの仲間 | 仲間は、勧誘したプレイヤーについていき、一緒に移動し、そのプレイヤーの仲間の上限にだけ数えられます。 |
| プレイヤーごとの出荷 | 出荷箱はひとつ。売上は、アイテムを入れたプレイヤーのものになります。 |
| 各自のペースの戦闘 | モンスターは、ホストではなく、戦っているプレイヤーのペースで動きます。 |
| プレイヤーごとのランダムクエスト | 住民や掲示板のクエストは、受けたプレイヤーのものです。報酬・名声・カルマもそのプレイヤーに入ります。どこへ行ってもついてきます。 |
| 共有のストーリー | ストーリークエストはひとつのログにあり、誰でも開始・進行・完了できます。見たダイアログ、キーアイテム、借金も共有です。 |
| 全員のダンジョンクエスト | ホスト以外のプレイヤーも、専用のゾーンを持つクエストを受けて、一人で、または二人で（次の行）こなせます。 |
| 二人でダンジョンクエスト | 一人がクエストに出ると、もう一人に同行するかどうかの「はい／いいえ」ボックスが出ます。ゾーンは共有、報酬はクエストを受けた人のものです。どちらの向きでも使えます。ゲストがクエストを受けた場合は、「討伐」・収穫・音楽のクエストに対応します（防衛は一人のままです）。 |
| プレイヤー間の取引 | 他のプレイヤーをクリック →「取引」：双方がアイテムとお金を出し、双方が確定します。 |
| より安全な取引 | ソロのゲームが手放せないとする物は拒否し、相手のバッグがいっぱいなら拒否し、理由を表示します。 |
| キャラクター選択 | 参加時に、そのワールドの自分のキャラクターから選ぶか、新しく作ります。 |
| プレイヤーごとのカルマと犯罪 | 悪事を働いたプレイヤーがカルマを失い、衛兵はそのプレイヤーだけを追います。 |
| 共有の好感度とギルド | 住民の好感度は全員で同じで、ギルドへの加入はグループ全体に有効です。 |
| ゲストもソロのプレイヤーと同じように遊べる | 0.26.399 以降の数十の修正：死亡と遺言、神の贈り物、罠、魔法書、治療師、祝福、出資、ルーン、自動整理、ホスト側で開いてしまっていたウィンドウ、山積みから取り出した贈り物、すでに乗られている騎乗動物、斧での丸太切り、仲間も癒やす祈り、バッグの食べ物の劣化…。一覧は [`dev/DOCUMENTATION.md`](dev/DOCUMENTATION.md)（フランス語）にあります。 |
| 「離れない」はプレイヤーごと | 仲間の距離の指示（「離れない」「うろつかない」）は、ホストのものではなく、そのプレイヤーのものです。 |
| ゲストによる拠点の設定 | 研究と拠点のスキルは、ホストへの本物のリクエストです（ホストが確認し、支払いは一度だけで、結果は全員に見えます）。政策、ベッド、販売タグ、メモ、拠点・派閥・テレポーターの名前は、もう一人のプレイヤーにも、どちらの向きでも反映されます。 |
| Elin のバージョンが違っても可 | 全員で同じでなければならないのは MOD のバージョンだけです。Elin のバージョンが違うプレイヤー同士でも接続でき、警告が表示されます。ホスト側のチェックボックス（「Require the same Elin version」、初期状態はオフ）で、Elin も同じバージョンにするよう求められます。 |

ほとんどは**ホスト側のチェックボックス**です（Esc → Mods → Elin Together → *Server Setting*）。チェックを外すと、MOD は元の動作に戻ります。二人でのダンジョンクエストと「ゲストもソロのプレイヤーと同じように遊べる」の修正には、チェックボックスはありません。

### 既知の制限

- Steam で 2 台の PC を使ってプレイしたのはごくわずか（一晩）で、このバージョンの新機能はまだです。
- ワールドの時間は、今もホストに従います。
- テストは、いくつかの場面（治療師、店、巫女）で、実際のゲームのダイアログをクリックするようになりました。ただしストーリーは別で、ホスト以外のプレイヤーが進めるストーリーのダイアログと、ダンジョンクエストの受注は、ゲームのコードを直接呼ぶテストです。
- 二人でダンジョンクエスト：ゲストがクエストを受けた場合は「討伐」のみです。収穫・音楽・防衛のクエストは、今も一人でこなします。
- ゲストが行う拠点の設定：研究、拠点（ホーム）のスキル、政策、ベッド、販売タグ、メモ、名前（拠点・派閥・テレポーター）はホストと同じように働きます。まだ未対応：メイド、住民の種別と待機、コンテナの設定（自分の画面にだけ反映されます）。
- ゲストの建築モード（床、壁、採掘・伐採の印）は、自分の画面でしか働きません。今のところ、拠点はホストが建ててください。
- Elin のバージョン違い：ローカル接続でのみ確認済みで、Steam のロビー経由は未プレイです。
- ホストが、ゲストの預かるマップに戻ると、ゲストの画面が再読み込みされます（事前に通知されます）。かかる時間は、2 台の PC ではまだ測っていません。
- 取引：装備中のアイテムは、今も取引できません（理由は表示されます）。バッグがいっぱいかどうかは確認されます。
- ゲーム内でまだ試していない修正があります：深い水での溺れ、接客チケット、ゲストが預かるマップでの訪問者のカルマ、バッグの並べ替え、派閥名、ほか（コミットのメッセージに「未プレイ」と記載）。
- 稀な競合が知られていて、未修正です（二人が同じマスに建てる、旅のあとに騎乗動物が二重になる）。同じ店で同時に二人が買うと、後の人に「もう無い」と通知されます（未プレイ）。
- 他の MOD との互換性は、元の MOD と同じです。MOD の一覧は短く、全員で同じにしてください。

完全な一覧と今後の予定は [`dev/DOCUMENTATION.md`](dev/DOCUMENTATION.md)（フランス語）にあります。

### このフォークのインストール

[YK Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=3400020753) と、Elin の **Nightly** ブランチが必要です（このフォークは EA 23.352 向けにビルドされています）。**全プレイヤーが同じビルドのこのフォークを使う必要があります**。Workshop 版とは通信しません。プレイヤー間で Elin のバージョンが少し違っていても、接続できなくなることはありません（警告が出ます。ホストは「Require the same Elin version」で同じバージョンを求められます）。

[Releases ページ](https://github.com/devmarcpro/elin-together/releases)から `ElinTogether-independance.zip` をダウンロードして展開し、`Installer.bat` を実行します（Workshop 版からこの版に切り替わります。`Desinstaller.bat` で元に戻せます）。インストーラーと付属の説明はフランス語です。

ホストするには：Steam から Elin を起動し、開拓地のあるセーブを読み込んでから、Esc → Mods → Elin Together。

このフォークの不具合は、[このリポジトリの Issue](https://github.com/devmarcpro/elin-together/issues) に、両方のプレイヤーの `Player.log` と `ElinMP/Logs/Session_<日付>.log`（`%USERPROFILE%\AppData\LocalLow\Lafrontier\Elin`）を添えて報告してください。このフォークの不具合を、元のプロジェクトには報告しないでください。

このフォークの変更は、AI コーディングアシスタント（Claude Code）を使い、フォークの所有者の指示で書かれました。変更ごとにゲーム内テストがあり、コミットのメッセージに記載されています。ゲームのファイルや、逆コンパイルしたゲームのコードは、このリポジトリに含まれていません。

[Steam ワークショップ](https://steamcommunity.com/sharedfiles/filedetails/?id=3773298709) または [GitHub Releases](https://github.com/ElinTogether/ElinTogether/releases) の自動ビルドからインストールできます。

### バージョン

ワークショップ版は常に最新の Nightly ビルドに対応しています。安定版で相性の問題が出た場合は、GitHub から Stable ビルドを入手できます。

### ホストを立てる

- **Steam から**ゲームを起動し、セーブをロードするか新規ゲームを開始（推奨）
- **Esc** → **Mods** → **Elin Together** でマルチプレイパネルを開く
- そこからホストを開始
- パネルから、または Steam のフレンドリストからプレイヤーを招待

![Elin Together パネル](https://i.postimg.cc/vHqQLbV0/Pix-Pin-2026-07-28-09-25-19.png)

フレンドと遊ぶ際は、MOD 構成をできるだけ少なく、全プレイヤーでまったく同じに揃えてください——共有にはワークショップのコレクションが便利です。

## FAQ

### 他のプレイヤーとコミュニケーションを取るにはどうすればいいですか？

マーカーを設置するには「P」キーを、チャットするには「Return」キーを押してください。

### ターン制のワールドはどう動くの？

プレイヤーはそれぞれ自分の速度で行動し、ホストのワールドがそれに合わせて進みます。行動は同時に進むので、お互いを待たせることはありません。設定で平均速度を共有することもできます。

### 戦闘はどうなるの？

このなめらかなターン同期システムに加えて、設定でクラシックなターン制戦闘も有効にできます。この場合、全員が行動を決めてからワールドが進みます。

### クライアント側でマップを移動できない

仕様です。マップを移動できるのはホストプレイヤーだけです。

### クライアント側で進まないクエストがある

仕様です。クライアントではエラーが出ることもあります。クエストを実際に進められるのはホストだけです。

### クライアント側に操作できないゴーストアイテムが見える

アイテムの同期がずれた場合は、再同期を行ってください。再同期の操作は、ホストまたはクライアントマシンのいずれかのパネルから実行できます。

### 接続がフリーズした・反応しない・入り直せない……

ゲームを再起動して、Steam の接続をクリーンアップしてください。

### <○○> MOD とは一緒に使える？

現時点では MOD の互換性サポートは行っていません。問題が発生した場合は、該当の MOD を外してお試しください。

## ビルド

本プロジェクトでは、以下の環境変数を設定する必要があります。

`ElinGamePath`: Elinのインストール先ルートディレクトリを指定します。
```
ElinGamePath/
├─ BepInEx/
│  ├─ core/
│  │  ├─ *.dll
├─ Elin_Data/
│  ├─ Managed/
│  │  ├─ *.dll
```

`SteamContentPath`: `YKFramework.dll` を参照できるようにするため、`steamapps/workshop/content` ディレクトリを指定します。

このプロジェクトのコンパイルには [.NET SDK 11.0](https://dotnet.microsoft.com/en-us/download/dotnet/11.0) が必要です。

プロジェクトをクローン：
```ps
git clone https://github.com/ElinTogether/ElinTogether.git
cd ElinTogether
```

依存関係のインストール：
```ps
dotnet restore ./ElinTogether --locked-mode
```

ビルド：
```ps
dotnet build ./ElinTogether -c Debug -o ./out --no-restore
```
