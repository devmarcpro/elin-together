ElinTogether - version "independance"
=====================================

Ce que c'est
------------
Une version modifiee du mod multijoueur Elin Together : en jeu, aucune difference entre l'hote et les autres
joueurs. Chacun va ou il veut sans suivre l'hote, avec ses compagnons, ses quetes, sa renommee et son argent ;
l'histoire, la base et les guildes restent communes.

Avant d'installer
-----------------
1. Avoir Elin sur Steam, a jour, sur le canal Nightly (Steam, clic droit sur Elin, Proprietes, Betas).
   Tous les joueurs doivent avoir la meme version du jeu : celle de version-elin.txt, dans ce dossier.
2. Etre abonne au mod "YK Framework" sur le Workshop Steam :
   https://steamcommunity.com/sharedfiles/filedetails/?id=3400020753
   Le plus simple : s'abonner a "Elin Together" sur le Workshop, il l'amene avec lui :
   https://steamcommunity.com/sharedfiles/filedetails/?id=3773298709
3. Lancer Elin une fois apres l'abonnement, puis le fermer.

Installer
---------
1. Dezipper tout le dossier.
2. Double-cliquer sur Installer.bat.
   Il trouve Elin, copie le mod, active cette version et desactive la version Workshop (c'est le meme mod).
3. Lancer Elin par Steam.

TOUS les joueurs doivent installer ce meme dossier : cette version ne se connecte pas a celle du Workshop.

Jouer
-----
- Ecran titre : bouton Elin Together. L'hote charge sa partie puis ouvre la session, les autres le rejoignent.
- L'hote doit avoir une base (un terrain revendique) dans sa partie.
- Reglages de l'hote, onglet "Server Setting" : une case a cocher par nouveaute, avec une ligne d'explication.
  Decochee, le mod se comporte comme l'original.
    * Independent travel                          chacun va ou il veut ; decoche : tout le monde suit l'hote
    * Players choose their character when joining en rejoignant : reprendre un de ses personnages ou en creer un
    * Shipping per player                         l'argent d'une vente va a celui qui a depose l'objet
    * Random quests, fame and karma per player    chacun ses quetes d'habitants, sa renommee, son karma
    * Trade window between players                clic sur un autre joueur, "Echanger"
    * Combat on each player's time                un monstre agit quand le joueur qu'il combat agit
    * Each player on its own clock                un invite marche aussi regulierement que l'hote
    * Every player walks at the pace of a solo game
                                                  la duree d'un pas ne depend plus de la vitesse des autres
    * Players can bring a character from their own saves (decochee au depart)
                                                  en rejoignant : "A character from one of my saves...", puis
                                                  la liste de ses sauvegardes. Le personnage vient avec son
                                                  equipement, son sac, son or, sa renommee et son karma ; pas
                                                  ses compagnons ni sa base. La sauvegarde n'est jamais modifiee.

Le serveur : ElinTogetherServer.exe
-----------------------------------
Un petit logiciel (un seul fichier, rien a installer). Il est en anglais. Double-cliquer dessus, choisir un
mode, puis "Start" (et "Stop" pour l'arreter).

Pour les joueurs, c'est pareil dans les deux modes : dans le jeu, bouton Elin Together, onglet "Lobby",
"Join by address", et taper une des adresses affichees par le logiciel, sous "Addresses to give to the
players (double-click to copy)". Une ligne sous la liste le rappelle. Le bouton reconnait tout seul le type de
serveur : il n'y a rien d'autre a regler. (Le jeu peut se figer jusqu'a 5 secondes si rien ne repond a cette
adresse.)

1) "Without Elin: keeps the world, a player hosts it" : le serveur garde le monde, les joueurs l'hebergent.
   Aucun jeu ne tourne sur le PC serveur, Elin n'a meme pas besoin d'y etre installe. Les adresses finissent
   par :55557 (port TCP).
   - Pour jouer : "Join by address" avec cette adresse. Si personne n'heberge, le jeu prend le monde et c'est
     ce joueur qui l'heberge : il ouvre la session comme d'habitude, les autres rejoignent de la meme facon.
     Si quelqu'un heberge deja, le jeu dit qui : il suffit de le rejoindre. Quand l'hebergeur quitte, un
     autre peut prendre le monde a son tour. Chaque sauvegarde retourne au serveur, qui garde aussi les trois
     mondes precedents.
   - Mot de passe : "Password (empty: none):" dans le logiciel. S'il y en a un, chaque joueur le met dans le
     jeu, onglet "Client Settings" (c'est l'une des raisons pour lesquelles ce reglage existe encore). Si le mot
     de passe est faux, le message du jeu n'est pas encore clair.
   - Choisir le monde : dans le logiciel, choisir une sauvegarde dans la liste (celles d'Elin sur ce PC,
     s'il y est) ou par "Browse..." (le dossier d'une sauvegarde copie d'un autre PC : celui qui contient
     game.txt), puis "Put this save on the server". La sauvegarde d'origine n'est pas modifiee.
   - Partir d'un monde neuf : un joueur cree une nouvelle partie comme d'habitude, puis, onglet "Lobby", bouton
     "Put this save in the depot" (il met la partie sur le serveur). Le serveur garde l'ancien monde a cote
     (world.1.zip).
   - Autre facon, toujours possible : onglet "Client Settings", champ "Depot" = l'adresse (par exemple
     192.168.1.28:55557), puis onglet "Lobby", bouton "Take the world from the depot and host it".

2) "With Elin on this PC: the world runs all the time" : le monde tourne en permanence, comme un serveur
   Minecraft. Elin doit etre installe sur le PC serveur ; il tourne derriere, sans fenetre (case "No game
   window (lighter)"). Choisir la sauvegarde (elle doit avoir une base). Les adresses finissent par :55556
   (port UDP). Le serveur sauvegarde toutes les cinq minutes tant que quelqu'un joue, et avant de s'arreter.
   (Serveur.bat fait la meme chose sans le logiciel, avec une fenetre de jeu.)
- Pour rejoindre : "Join by address" avec l'adresse du PC serveur (le logiciel, ou Serveur.bat, affiche les
  adresses possibles).
- Depuis Internet : ouvrir le port 55556 (UDP) de la box vers le PC serveur (55557 en TCP pour le mode sans
  Elin), ou utiliser un reseau prive (Tailscale, ZeroTier...) et donner l'adresse que ce reseau attribue au
  PC serveur.
- Tout le monde est invite : chacun va ou il veut, le monde continue quand quelqu'un part.

Le depot sans serveur du tout : un dossier partage
--------------------------------------------------
A la place du logiciel, un dossier que tout le groupe peut atteindre (dossier partage, ou synchronise par un
logiciel de partage de fichiers) peut garder le monde. Dans le jeu : onglet "Client Settings", "Depot", et
donner le chemin de ce dossier au lieu d'une adresse. Chaque joueur le regle une fois.
- Pour y mettre un monde : charger sa partie, onglet "Lobby", "Put this save in the depot".
- Pour jouer : a l'ecran titre, onglet "Lobby", "Take the world from the depot and host it", puis ouvrir la
  session comme d'habitude. Les autres rejoignent. Chaque sauvegarde retourne au depot.
- Si quelqu'un heberge deja, le bouton dit qui : il suffit de le rejoindre.
- Quand celui qui heberge quitte, un autre peut prendre le monde a son tour.

Revenir en arriere
------------------
Double-cliquer sur Desinstaller.bat : retire cette version et reactive la version Workshop.
Rien n'est supprime : les anciennes versions sont gardees dans Elin\_ElinTogether_sauvegarde.

A savoir
--------
- C'est une version de test, verifiee surtout sur un seul PC avec plusieurs fenetres du jeu. Le serveur sans
  Elin a ete essaye une fois entre deux PC du meme reseau local (connexion et prise du monde). Pas encore
  essaye : par Internet, le mode avec Elin entre deux PC, un deuxieme joueur qui rejoint, l'hebergeur qui part.
  Faites une copie de vos sauvegardes avant de jouer :
  %USERPROFILE%\AppData\LocalLow\Lafrontier\Elin
- Le temps du monde est commun a tous les joueurs ; meteo, impots et salaires ne passent qu'une fois.
- Quetes a donjon : seul celui qui prend la quete entre dans sa zone.
- Un probleme ? Envoyez Player.log et ElinMP\Logs\Session_<date>.log (meme dossier que les sauvegardes),
  ceux des deux joueurs : https://github.com/devmarcpro/elin-together/issues
